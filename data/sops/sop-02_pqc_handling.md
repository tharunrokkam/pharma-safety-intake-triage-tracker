# SOP-02 Product Quality Complaint Handling (Fictional Training SOP)

Fictional procedure for the training prototype.

## 1. Purpose
Describes how to log a product quality complaint (PQC) such as damaged packaging, discoloured tablets, cracked or broken tablets, particulate matter, leaking containers or incorrect labelling.

## 2. Required Information
Record the product name, batch or lot number (LOT-12345 format), date received, reporter type and a factual description of the defect. Event description and onset date are not applicable to product quality complaints and must be left empty.

## 3. Sample Retention
If the reporter still has the affected units, note in the description whether a sample is available for return. Do not request or store the reporter's home address in this system.

## 4. Batch Trending
Quality reviewers search prior complaints by lot number to identify repeated defects in the same batch. Use the exact lot identifier, for example LOT-10457, so that keyword search returns every related complaint.

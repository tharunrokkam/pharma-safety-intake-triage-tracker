# SOP-05 Batch and Lot Lookup (Fictional Training SOP)

Fictional procedure for the training prototype.

## 1. Lot Number Format
All batch or lot numbers use the format LOT- followed by exactly five digits, for example LOT-88392. Entries such as "lot 88392" are normalised to LOT-88392 by the intake tool; entries with the wrong number of digits are rejected.

## 2. Historical Search
Use the Knowledge Agent to search past reports by exact lot number, product name or symptom wording. The hybrid search combines exact keyword matching for identifiers with semantic matching for descriptions, so both "LOT-88392" and "trouble breathing" style queries return relevant history.

## 3. Interpreting Results
Search results are quoted directly from stored fictional records with their reference identifiers. If no record is relevant enough the agent states that nothing was found rather than guessing.
